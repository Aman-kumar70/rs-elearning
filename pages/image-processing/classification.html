Turning Pixels Into Classes

This is the payoff of everything so far: turning a corrected, enhanced grid of numbers into a map that says "this pixel is forest, this one is water, this one is urban" — automatically, across millions of pixels, using the spectral signatures from RS.2.

04.1 / The Core Idea

Classification is nearest-neighbour matching in spectral space

What

Image classification assigns every pixel to one of a fixed set of land-cover classes (water, forest, urban, agriculture...) based on its spectral signature — the DN values across all available bands, treated as a point in multi-dimensional "spectral space."

Why

Because a visually interpreted map (RS.5) doesn't scale — you can't manually label every pixel across a whole country, repeated every season. Classification automates exactly the kind of tone/pattern judgement a human interpreter makes, at planetary scale.

How

Every pixel's band values are treated as a vector. The algorithm either compares that vector to known reference signatures you provide (supervised), or groups similar vectors together without any prior labels and lets you name the resulting clusters afterward (unsupervised).

Spectral Space, Visualized

Each dot is one pixel, plotted by its Red-band DN (x-axis) and NIR-band DN (y-axis) — exactly the two-band version of what a classifier does with many bands at once. Notice how land-cover types naturally cluster.

04.2 / Supervised vs Unsupervised

Two opposite starting points

🎯

Supervised Classification

You start by defining training samples — pixels you (or ground-truth data) know belong to each class. The algorithm learns the statistical signature of each class from those samples, then classifies every remaining pixel by comparing it to those learned signatures.

Common algorithms: Maximum Likelihood, Minimum Distance, Support Vector Machine, Random Forest.

🧩

Unsupervised Classification

No training samples needed. The algorithm groups pixels purely by spectral similarity into a chosen number of clusters (K). You examine the resulting clusters afterward and assign each one a meaningful land-cover label.

Common algorithms: K-Means, ISODATA.

Maximum Likelihood — the Classic Supervised Algorithm

Maximum Likelihood Classification assumes each class's pixels form a (multivariate) Gaussian cluster in spectral space, defined by a mean vector and covariance matrix estimated from training samples. For any new pixel, it computes the probability that pixel belongs to each class given those Gaussian distributions, and assigns the class with highest probability — accounting not just for distance to the class mean, but how "spread out" and correlated that class's bands tend to be.

💡
Plain English

Supervised classification is like sorting a basket of laundry when someone has already shown you five example red shirts, five blue shirts, and five towels — you learn what each pile "looks like" first, then sort the rest. Unsupervised is sorting the same basket with no examples at all — you just group items that look similar to each other, ending up with piles you then have to inspect and label yourself ("oh, this pile is all towels"). Maximum Likelihood specifically doesn't just ask "which pile's average shirt do I look most like" — it also considers how much each pile's items typically vary, the way you'd expect more variation among "blue shirts" than among "white towels."

04.3 / Accuracy Assessment

A classified map is worthless without a number attached

Never trust an unchecked classification. Accuracy assessment compares the classified map against independent, trustworthy reference points (field visits, high-resolution imagery, existing verified maps) — usually withheld from training — and summarizes agreement in a confusion matrix.

Producer's accuracy (per column): of all true Forest reference points, what % were correctly classified as Forest? User's accuracy (per row): of all pixels the map calls Forest, what % are actually Forest on the ground? Kappa coefficient goes further, correcting overall accuracy for the agreement expected by pure chance.
💡
Plain English

Overall accuracy is like a test score — how many you got right out of the total. But imagine a test where 90% of answers were "True" — you could score 90% just by guessing "True" every time, without knowing anything. Kappa asks the harder question: "how much better did the classifier do than random guessing would have scored, given how common each class already is?" A Kappa near 1.0 means genuinely skillful classification; a Kappa near 0 means it's barely beating a coin flip, even if the raw accuracy number looked impressive.

accuracy_assessment.py
from sklearn.metrics import confusion_matrix, classification_report, cohen_kappa_score

# y_true, y_pred: class labels at independent, withheld reference points
cm = confusion_matrix(y_true, y_pred)
kappa = cohen_kappa_score(y_true, y_pred)

print(classification_report(y_true, y_pred,
      target_names=["Water","Forest","Urban","Crop"]))
print(f"Kappa coefficient: {kappa:.3f}")
# Water precision 0.98 recall 0.96 f1-score 0.97
# Forest precision 0.93 recall 0.95 f1-score 0.94
# ...
# Kappa coefficient: 0.902
Try It Yourself

In the confusion matrix above, Forest and Crop are confused with each other more than with Water or Urban (6 + 8 misclassifications). That makes spectral sense — both are vegetation, occupying nearby regions of spectral space (RS.2). Adding a SWIR band, a texture measure, or a time-series (crops change faster than forest) typically resolves exactly this kind of confusion.

Key Takeaways
  • Classification assigns every pixel to a class using its position in spectral space — the multi-band equivalent of the signature charts from RS.2.
  • Supervised classification needs labelled training samples; unsupervised (K-Means, ISODATA) groups pixels by similarity with no prior labels.
  • Maximum Likelihood is the classic statistical supervised method; modern workflows often use Random Forest or SVM instead.
  • A classified map is meaningless without accuracy assessment against independent reference data — overall accuracy, producer's/user's accuracy, and Kappa.
  • Classes that are spectrally similar (e.g. forest vs. crop) are the ones most often confused — more bands, texture, or time-series data usually help.
