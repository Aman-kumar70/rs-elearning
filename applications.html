Case Study 1
RS.2 + IP.3

Crop Health & Yield Monitoring

Farmers and agencies track crop vigour across entire regions using time-series NDVI — the vegetation signature from RS.2, applied as a repeated measurement rather than a single snapshot.

Workflow

Fetch a cloud-free Sentinel-2 or Resourcesat AWiFS scene every 5–16 days through a growing season → compute NDVI per date (IP.3) → stack into a time series per field → compare against historical averages or neighbouring fields to flag stress early, often weeks before it's visible on the ground (because NIR reflectance drops before visible colour changes — RS.2).

ndvi_timeseries.py
import pandas as pd

results = []
for date, scene in scenes_by_date.items():
    ndvi = (scene["nir"] - scene["red"]) / (scene["nir"] + scene["red"] + 1e-6)
    field_mean = ndvi[field_mask].mean()   # field_mask = boolean array of the farm boundary
    results.append({"date": date, "mean_ndvi": field_mean})

df = pd.DataFrame(results).sort_values("date")
df.plot(x="date", y="mean_ndvi", title="Field NDVI Over the Growing Season")
Case Study 2
RS.1 + RS.3

Flood Mapping Through Cloud Cover

Floods happen during monsoons and storms — exactly when optical satellites are blind (RS.1: passive sensors need clear sky and sunlight). SAR (active microwave, RS.3) sees straight through cloud, rain, and darkness, which is why RISAT and Sentinel-1 are the standard tools for flood response.

Workflow

SAR measures backscatter — how much of the sent radar pulse bounces back. Calm open water acts like a mirror, reflecting the pulse away from the sensor (very low backscatter, appears dark). Land and vegetation scatter the pulse back diffusely (bright). Compare a flood-event SAR image against a pre-flood baseline of the same area: newly dark pixels = newly flooded land.

sar_flood_delta.py
import numpy as np

# Both images: Sentinel-1 VV backscatter, in dB, same area
def flood_extent(pre_event_db, during_event_db, threshold_db=-3):
    change = during_event_db - pre_event_db
    # A sharp drop in backscatter = surface became smooth = likely flooded
    flood_mask = change < threshold_db
    flooded_area_km2 = flood_mask.sum() * (10*10) / 1e6   # 10m pixels -> km²
    return flood_mask, flooded_area_km2

mask, area = flood_extent(pre_flood, during_flood)
print(f"Estimated flooded area: {area:.1f} km²")
Case Study 3
IP.3 + IP.4

Deforestation & Land-Cover Change Detection

Classify the same area at two different dates (IP.4), then compare pixel by pixel — any pixel that flips from "Forest" to "Bare Soil / Cleared" between classifications is flagged as loss.

change_detection.py
import numpy as np

# classified_2020, classified_2025: same-extent classified maps, same class scheme
FOREST, CLEARED = 1, 3

deforestation_mask = (classified_2020 == FOREST) & (classified_2025 == CLEARED)
pixel_area_ha = (30*30) / 10000   # 30m Landsat pixel -> hectares
lost_hectares = deforestation_mask.sum() * pixel_area_ha

print(f"Forest lost 2020→2025: {lost_hectares:,.0f} hectares")
# Forest lost 2020→2025: 4,812 hectares
Why Long-Running Missions Matter

This is exactly why Landsat's 50+ year continuous archive (RS.6) is irreplaceable — comparable, calibrated imagery going back to 1972 means you can build a deforestation timeline decades long, using consistently processed data rather than piecing together incompatible sensors.

Case Study 4
RS.2 + RS.4

Himalayan Glacier Retreat

Glacier boundaries are mapped using the snow/ice spectral signature (RS.2) — high visible reflectance, sharp drop-off in SWIR — automated with a simple band-ratio threshold (the Normalized Difference Snow Index, structurally identical to NDVI but using Green and SWIR bands instead of NIR and Red).

NDSI = (Green − SWIR) / (Green + SWIR)
NDSI > 0.4 is the conventional threshold for "snow/ice." Comparing glacier-boundary area across decades of Landsat imagery (RS.4: choosing 30m spatial resolution matched to the multi-decade temporal resolution needed) is the standard method for tracking retreat.
Case Study 5
IP.2 + IP.3

Urban Growth Mapping

City planners track built-up area expansion the same way as deforestation, but in reverse — classifying "Built-up" instead of "Forest" across a multi-decade Landsat time series, geometrically corrected (IP.2) so every year's map aligns to the same pixel grid, letting simple subtraction reveal exactly where new construction occurred.

Try It Yourself

Every case study above reuses the same five ingredients: (1) pick the right bands based on the signature you care about, (2) preprocess and enhance, (3) compute an index or classify, (4) compare across time or space, (5) validate. That pattern — not any single algorithm — is the actual skill this course teaches.
