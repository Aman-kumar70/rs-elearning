Enhancement, Filtering & Indices

Preprocessing fixes errors; enhancement makes correct data easier to interpret — for a human eye or a downstream algorithm. This is the longest chapter in the course because it's the one you'll use constantly: contrast stretching, spatial filters, band ratios, vegetation indices, and PCA.

03.1 / Contrast Enhancement

Most raw imagery uses only a sliver of its dynamic range

What

Contrast stretching remaps a narrow range of DN values onto the full display range (0–255), so subtle differences become visible. Raw sensor data — especially 11/12-bit imagery displayed on an 8-bit screen — usually occupies only a small, low-contrast slice of the possible range.

Why

Because a human eye (and many algorithms) can't distinguish DN 512 from DN 515 when both display as nearly the same shade of grey. Stretching those two values apart makes real, meaningful differences in the data visible.

How

A linear transformation function maps input DN to output DN. Min-max stretch uses the image's actual min/max; percentage-cutoff and standard-deviation stretches ignore extreme outlier pixels for a more robust result; non-linear stretches (logarithmic, histogram equalization) redistribute contrast unevenly on purpose.

DNout = (DNin − Min) / (Max − Min) × 255
Linear min-max stretch. Min/Max can come from the true image extremes, a fixed percentile cutoff (e.g. 2%–98%, ignoring outliers), or the mean ± n standard deviations — each variant trades robustness against extreme pixels for how aggressively it stretches the "typical" range.
contrast_stretch.py
import numpy as np
from skimage import exposure

def linear_stretch(band, low_pct=2, high_pct=98):
    lo, hi = np.percentile(band, [low_pct, high_pct])
    stretched = np.clip((band - lo) / (hi - lo), 0, 1) * 255
    return stretched.astype("uint8")

# Histogram equalization — one line with scikit-image
equalized = exposure.equalize_hist(band)

# CLAHE — adaptive equalization, avoids over-amplifying noise in flat regions
clahe = exposure.equalize_adapthist(band / band.max(), clip_limit=0.03)
03.2 / Spatial Filtering

Convolution: the operation behind every filter

Spatial filters change a pixel's value based on its neighbours, using a small moving window ("kernel" or "mask"). This single mechanism — convolution — implements smoothing, sharpening, noise removal, and edge detection, just by changing the numbers in the kernel.

BVout = ΣΣ (kernel × window) ÷ Σ(kernel)
The heart of spatial filtering — a weighted average of a pixel's neighbourhood. A uniform kernel of all 1s produces smoothing; a kernel with negative side-weights and a large positive centre produces sharpening.
spatial_filters.py
import numpy as np
from scipy.ndimage import convolve, sobel

# Low-pass 3x3 mean filter — smoothing
mean_kernel = np.ones((3,3)) / 9
smoothed = convolve(band, mean_kernel)

# High-pass sharpening kernel
sharpen_kernel = np.array([[ 0,-1, 0],
                            [-1, 5,-1],
                            [ 0,-1, 0]])
sharpened = convolve(band, sharpen_kernel)

# Sobel edge detection — magnitude of gradient in X and Y
edges_x = sobel(band, axis=0)
edges_y = sobel(band, axis=1)
edge_magnitude = np.hypot(edges_x, edges_y)
03.3 / Band Math — Ratios & Indices

Combining bands reveals what single bands hide

Band ratios divide one band by another, pixel-by-pixel. This cancels out effects that influence all bands roughly equally (topographic shading, seasonal illumination differences) while amplifying the specific spectral contrast between the two chosen bands (RS.2).

compute_ndvi.py
import numpy as np

red = image[2].astype("float32")
nir = image[3].astype("float32")

ndvi = (nir - red) / (nir + red + 1e-6)     # epsilon avoids divide-by-zero

print(f"Mean NDVI: {ndvi.mean():.3f}")
print(f"Healthy vegetation pixels (NDVI>0.5): {(ndvi>0.5).sum()}")

plt.imshow(ndvi, cmap="RdYlGn", vmin=-1, vmax=1)
plt.colorbar(label="NDVI")
# Mean NDVI: 0.412
# Healthy vegetation pixels (NDVI>0.5): 184,302
03.4 / Principal Component Analysis

Compressing correlated bands into independent ones

Adjacent spectral bands are often highly correlated — a bright pixel in the red band is usually bright in green too. PCA finds new axes (principal components) along which the data varies most, decorrelating the bands. PC1 typically captures overall brightness; later components often isolate subtle features buried in the correlation.

pca_bands.py
from sklearn.decomposition import PCA
import numpy as np

bands, rows, cols = image.shape
pixels = image.reshape(bands, -1).T        # shape: (rows*cols, bands)

pca = PCA(n_components=bands)
components = pca.fit_transform(pixels)
print("Variance explained per PC:", pca.explained_variance_ratio_)

pc_image = components.T.reshape(bands, rows, cols)  # back to image shape
# Variance explained per PC: [0.891 0.081 0.021 0.007]
Try It Yourself

In the output above, PC1 alone explains 89% of the variance across four bands — that's the "correlated brightness" everything shares. PC2 through PC4 hold the remaining 11%, but that's often exactly where the interesting, band-specific differences live. This is why PCA is a common step before classification (IP.4): fewer, decorrelated inputs, same information.

Key Takeaways
  • Contrast stretching remaps a narrow DN range to the full display range — linear (min-max, percentile-cutoff, std-dev) or non-linear (log, histogram equalization).
  • Spatial filtering is convolution with a kernel: uniform kernels smooth (low-pass), centre-weighted kernels sharpen (high-pass), zero-sum kernels detect edges (Sobel, Roberts, Prewitt).
  • Band ratios cancel shared effects (topography, illumination) and amplify the spectral contrast between two chosen bands — the basis of NDVI and geological ratio mapping.
  • PCA decorrelates bands into independent components ranked by variance explained, often revealing detail buried by inter-band correlation.
  • All of this is ordinary array math — every technique above is a handful of lines with NumPy, SciPy, scikit-image, or scikit-learn.
